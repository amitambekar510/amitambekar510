## About me

I'm **Amit Ambekar**, a cyber defense architect and threat intelligence researcher building practical tools and frameworks for security operations teams. My work connects **threat intelligence, detection engineering, incident investigation, and automation** — and, more and more, **AI-ready projects that anyone can pick up and use**.

I focus on making security knowledge usable: enriching indicators, structuring investigations, documenting SOC operations, and helping analysts move from an alert to an informed decision. Through **The Safehouse** I share practical cybersecurity knowledge, and **The Safehouse Academy** is launching soon with a **Cyber Security &amp; Audit Ready Course**.

## AI-ready open projects

Several of my projects are built to work **with your AI assistant**. Point an assistant that can read GitHub files at a repository, answer its guided questions, and receive a ready-to-review deliverable — a PDF report, a SOC roster, a customized handbook, an adoption plan, or a personal study path. They are free for everyone to use: **just add AI and start.**

No GitHub access in your assistant? Download the repository ZIP, attach it, and use the same prompt.

> **Use responsibly:** these are AI-assisted frameworks, not hosted services. Review every output, never paste secrets or customer data into prompts, and check each repository's license — terms differ between projects (for example MIT for ShiftGuard and SOC Career Launchpad, custom open-use terms for the Handbook and AnySIEM-Reports).
